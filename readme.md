# Tre i rad

En implementation av spelet "Tre i rad" i retrostil.

## Förkrav

- Node + npm

## Komma igång
Alla nödvändiga resurser kommer färdigbyggda. Det som behövs är att starta en webbserver som servar `index.html`:
 1. `npm install` i root.
 2. `npm run serve`  för att starta lokal webbserver på port 8080.
 3. Öppna `http://localhost:8080/` i webbrowser. 

OBS! Spelet är endast testat i Chrome.
